# Local Runner (Web UI)

รันโปรแกรมจาก ไฟล์ / โฟลเดอร์ / .zip ด้วย portable runtime แสดงผล real-time บนหน้าเว็บ
ใช้ Python stdlib ล้วน ไม่ต้องติดตั้ง customtkinter หรือ tkinterdnd2

> **ความปลอดภัย:** ไม่ใช่ sandbox จริง โค้ดที่รันมีสิทธิ์เท่ากับผู้ใช้ปัจจุบัน ตัวแปร env ที่ชื่อมี
> KEY, TOKEN, SECRET, PASSWORD, CREDENTIAL จะไม่ถูกส่งต่อให้โปรแกรมที่รัน ใช้กับโค้ดที่ไว้ใจได้เท่านั้น
> ตัวหน้าเว็บเองป้องกันเว็บอื่นสั่งรันโปรแกรมผ่าน localhost ด้วย token สุ่มต่อการเปิดแต่ละครั้ง + ตรวจ Host header

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `runner.py` | Logic: หา entry point, รัน, stream output, cleanup (ไม่รู้จัก UI) |
| `server.py` | Web layer: HTTP server + API + สถานะ/log สำหรับหน้าเว็บ |
| `dbview.py` | ดูฐานข้อมูลแบบอ่านอย่างเดียว (SQLite / CSV) ไม่รู้จัก HTTP |
| `history.py` | ประวัติการรัน + คะแนน/ข้อความ (SQLite) ไม่รู้จัก HTTP |
| `app.py` | จุดเริ่มต้น เปิด server แล้วเปิดเบราว์เซอร์ |
| `web/index.html` | โครงหน้า |
| `web/style.css` | สีและเลย์เอาต์ (palette อยู่ที่ `:root` บนสุด) |
| `web/app.js` | พฤติกรรมหน้าเว็บ: อัปโหลด, drag-drop, poll output |
| `test_runner.py`, `test_server.py` | เทสต์ |

## Setup
    pip install pytest pyinstaller
    python -m pytest

วาง portable runtime (ไม่รวมอยู่ในโปรเจกต์):
    runtime/python/python.exe   # Python embeddable package
    runtime/node/node.exe       # Node.js standalone binary

## Run
    python app.py

## วิธีเลือกสิ่งที่จะรัน
- **ลากวาง / Browse / Folder:** เบราว์เซอร์ไม่ให้ path จริงของไฟล์ที่ลากมา จึงอัปโหลดสำเนาไปที่โฟลเดอร์ temp แล้วรันจากสำเนา
  (ลบทิ้งเมื่อปิดโปรแกรม หรือเมื่อเลือกอันใหม่) โฟลเดอร์ใหญ่ เช่นที่มี `node_modules` จะช้า
- **วาง path:** รันจากที่เดิมในเครื่อง ไม่อัปโหลด แนะนำสำหรับโฟลเดอร์ใหญ่หรือโปรเจกต์ที่ต้องเขียนไฟล์กลับที่เดิม

## เลือก Python runtime (ลำดับความสำคัญ)
1. `runtime/python/python.exe` ถ้าเป็น Python แบบเต็ม (มี pip, tkinter, venv ครบ)
2. Python ที่กำลังรัน `app.py` อยู่ (ตอนรันจาก source) หรือ Python แบบเต็มใน PATH
3. Embeddable (ตัวเลือกสุดท้าย ไม่มี tkinter) แนะนำให้ใช้ Python แบบเต็มเพื่อรองรับทุก library

## ภาษาที่รองรับ
`.py` `.js` `.bat` `.cmd` `.exe` `.html` ใช้ runtime ในตัว
`.php` ใช้ `runtime/php/php.exe` (ถ้าวางไว้) หรือ php ใน PATH: ถ้าเป็นหน้าเว็บ (`index.php` หรือมี `$_GET`/`$_POST`/HTML) จะรันด้วย `php -S` แล้วเปิดเบราว์เซอร์ให้ ถ้าเป็นสคริปต์ธรรมดาจะรันเป็น CLI และเปิด extension (PDO/SQLite/MySQL ฯลฯ) ให้เองถ้า php.exe ไม่มี php.ini
`.ps1` `.sh` `.jar` `.rb` `.pl` `.go` `.lua` ใช้ interpreter ที่ติดตั้งในเครื่อง (ถ้าไม่มีจะแจ้งใน log)

## ติดตั้ง library อัตโนมัติ
ก่อนรันโปรแกรม Python จะอ่าน `requirements.txt` หรือ `pyproject.toml` (ถ้ามี) หรือสแกน `import` แล้ว `pip install --target` ไปที่
`~/.local_runner/deps/` (cache ใช้ซ้ำได้) ถ้า runtime เป็น Embeddable จะเปิด `import site` และติดตั้ง pip ให้เอง
โดยต้องวาง `get-pip.py` ไว้ข้าง `python.exe` และต้องต่ออินเทอร์เน็ตตอนติดตั้งครั้งแรก

## ประวัติและการตรวจงาน
ทุกครั้งที่กด Run ระบบบันทึกประวัติอัตโนมัติ: เวลา, ชื่อไฟล์/โฟลเดอร์, สถานะ (สำเร็จ / ผิดพลาด / หยุดโดยผู้ใช้ / ถูกขัดจังหวะ),
exit code และ **output ทั้งหมด** (รวมข้อความที่พิมพ์ตอบ `input()`) เก็บได้สูงสุด 200,000 ตัวอักษรต่อครั้ง
- **หน้ารันโปรแกรม:** พอรันจบจะมีกล่อง "ตรวจงาน" ให้ตั้งชื่อ (เช่น ชื่อนักเรียน) ให้คะแนน (คะแนน / เต็ม) และเขียนข้อความสั้น ๆ ไม่เกิน 500 ตัวอักษร
  ค่า "เต็ม" จะจำค่าล่าสุดไว้ เพื่อตรวจทั้งห้องด้วยเต็มเท่ากัน
- **แท็บประวัติ:** ค้นหา (ชื่อ/ไฟล์/ข้อความ) กรอง (ยังไม่ให้คะแนน / ให้คะแนนแล้ว) เรียงใหม่สุด/เก่าสุดก่อน สรุปจำนวนและคะแนนเฉลี่ย
  คลิกแถวเพื่อดู output ที่บันทึกไว้ แก้ชื่อ/คะแนน/ข้อความ และกด "บันทึกและไปรายการถัดไป" เพื่อตรวจต่อเนื่อง
- **รันซ้ำ:** ใช้ได้กับรายการที่รันจาก path (รายการที่อัปโหลด/zip ไม่มีไฟล์ต้นฉบับเก็บไว้ จึงรันซ้ำไม่ได้ แต่ยังดู output ได้)
- **ส่งออก CSV:** เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน ชื่อที่ขึ้นต้นด้วย `= + - @` จะถูกใส่ `'` นำหน้า กันถูกตีความเป็นสูตร
- **ที่เก็บข้อมูล:** `history/history.db` ในโฟลเดอร์เดียวกับ `app.py` (ถ้า build เป็น .exe จะอยู่ข้าง `app.exe`) เปลี่ยนที่ได้ด้วยตัวแปรสภาพแวดล้อม `LSR_HISTORY`
  ครั้งแรกที่เปิด ถ้าไม่มีไฟล์ใหม่แต่มีไฟล์เก่าที่ `~/.local_runner/history.db` จะคัดลอกมาให้ (ไฟล์เก่าไม่ถูกลบ) ควรใส่ `history/` ใน `.gitignore` เพราะมีชื่อและคะแนนนักเรียน
  เป็นไฟล์ SQLite ธรรมดา เปิดดูในแท็บ "ฐานข้อมูล" ได้ ข้อมูลไม่ถูกเข้ารหัส และจะไม่ถูกลบเองจนกว่าจะกดลบ

## เว็บแอปที่รันอยู่ (Flask / Django / FastAPI / Node ฯลฯ)
ถ้าโปรแกรมพิมพ์ที่อยู่เว็บ เช่น `Running on http://127.0.0.1:5000` หรือ `listening on port 3000`
ระบบจะแสดงปุ่ม "เปิด http://..." เหนือหน้าต่างผลลัพธ์ (เปิดในแท็บใหม่เต็มหน้า) และถ้าติ๊ก "เปิดเว็บอัตโนมัติ"
จะเปิดเบราว์เซอร์ให้เองเมื่อพอร์ตพร้อมรับการเชื่อมต่อ ปุ่มหายไปเมื่อโปรแกรมหยุด

## แท็บ "ฐานข้อมูล"
เปิดไฟล์ SQLite (ตรวจจากเนื้อไฟล์ ไม่ขึ้นกับนามสกุล) หรือ `.csv` (รองรับ UTF-8 และ cp874 ของ Excel ไทย, ตัวคั่น , ; | tab)
ดูรายชื่อตาราง/view, เปิดทีละหน้า, ค้นหาทุกคอลัมน์, คลิกหัวคอลัมน์เพื่อเรียง และรัน SQL ได้ (SELECT เท่านั้น)
ปลอดภัยต่อข้อมูล: เปิดแบบ read-only, บล็อก ATTACH/PRAGMA ที่เขียนได้, 1 คำสั่งต่อครั้ง, จำกัดเวลา 8 วินาที และ 1,000 แถว
ถ้ารันโปรเจกต์จาก path ไว้แล้ว จะมีรายการไฟล์ `.db/.sqlite/.csv` ในโปรเจกต์นั้นให้เลือก
ยังไม่รองรับ MySQL / PostgreSQL (ต้องมีการเชื่อมต่อด้วยรหัสผ่าน)

## ปิดโปรแกรม
กดปุ่ม "ปิดโปรแกรม" บนหน้าเว็บ ถ้าแค่ปิดแท็บ โปรแกรมจะปิดตัวเองหลังไม่มีการเชื่อมต่อ 120 วินาที
(และจะไม่ปิดถ้ายังมีโปรแกรมที่รันอยู่)

## Package
    pyinstaller --onedir --noconsole --add-data "runtime;runtime" --add-data "web;web" app.py

## ลำดับการหา Entry Point
`main.py` → `index.js` → `run.bat` → `index.html` → (ถ้าไม่เจอ) ไฟล์ที่รันได้เพียงไฟล์เดียวในโฟลเดอร์
